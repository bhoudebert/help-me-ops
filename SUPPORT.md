# Support

- **Something broken**: open a bug report with the issue template: the command
  or question, the output, and `npm run ops -- sources`.
- **An idea**: open a feature request, or check `ROADMAP.md` first.
- **A question on usage**: an issue with the `question` label.
- **A security concern**: see `SECURITY.md`; do not open a public issue.

This is a personal open-source project maintained on spare time. Answers can
take a few days.
